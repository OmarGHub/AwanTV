# TCL "Smart TV Pro" (G08 board, MediaTek, Android 14 Google TV): what AwanTV-clean.ps1 disables.
# From CleanYourTV (github.com/Gathin23/cleanyourtv, MIT): examples/tcl-c755-google-tv and tcl-qm6k-google-tv,
# both "Smart TV Pro" on the same board, applied and checked on real sets. Only the lines both lists have in their
# tracking, promo, demo and preload parts; what an owner may use (casting, AirPlay, Miracast, USB media, game bar,
# streaming apps, YouTube Music) is left on. Unlike CleanYourTV, Awan TV keeps the stock launcher (launcherx), the
# screensaver (dreamx) and setup (setupwraith): Awan TV runs over them.
# One package a line; "#" starts a comment. Disabled for the user (pm disable-user), never uninstalled.
